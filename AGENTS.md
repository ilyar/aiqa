## Project orchestration

Use `.codex/orchestration/POLICY.md` for task routing, delegation contracts,
verification, metrics and project memory. This project explicitly requests
subagent delegation for the bounded tasks specified by that policy. Routine
actions use the fast route without research or planning agents.

Read `.orchestration/PROJECT.md` for verified project commands and boundaries.
`.orchestration/project-observed.json` contains automatically discovered
candidates, not authoritative commands. Validate candidates against CI and the
repository before using them. Existing and nested project instructions still
apply. User requests and runtime permissions take precedence over this policy.
