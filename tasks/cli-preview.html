Статические состояния интерфейса из tasks/next.md. Все счётчики, ETA и verdicts — синтетические. Макет не обращается к провайдерам, не запускает проверки и не представляет новый HTML-формат отчёта AIQA.

JOBS ≠ HTTP requests
Job — workflow проверки. Один job может выполнить много запросов. HTTP 9/16 означает девять фактических запросов в общем лимите 16.
Процент ≠ остаток времени
90% завершённых jobs не обещают, что осталось 10% времени. ETA учитывает очередь, зависимости, pacing, cooldown и разные типы работы.
DONE ≠ PASS
Завершённый target может не пройти профиль. Вынесены отдельно execution state, conformance verdict и целостность forensic trace.


Что можно менять на design review
Порядок и ширину колонок, плотность details, ASCII/Unicode glyphs, palette и расположение итогов. Нельзя убирать названия единиц времени, скрывать неизвестный ETA, превращать общий cap в лимит на каждый target или подменять outcome прогрессом.
NO_COLOR отключает только цвет; в реальном CLI --progress=plain также отключает управляющие последовательности. Здесь кнопки меняют только статический макет. При нехватке ширины окна просмотр прокручивается; выбранный размер терминала остаётся явным.
